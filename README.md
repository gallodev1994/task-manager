# 📝 Task Manager Project

Now you can manage your tasks without database persistence !
With Task manager you can

- create a task
- update a task
- delete a task

The stack of project is:

Frontend: **Next.js**, **Tailwind**.
Backend: **TRPC**

First, clone project:

```bash
git clone https://github.com/gallodev1994/task-manager
cd task-manager
```

After it, run project:

```bash
npm run start
# or
yarn start
# or
pnpm start
# or
bun start
```
